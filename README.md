# Goodform Clothing Store

A responsive front-end e-commerce web application for browsing apparel, managing a shopping cart, tracking orders, and administering store inventory.

## Features

- **Storefront (`index.html`):** Browse featured collections, clothing categories, and product listings.
- **User Authentication (`login.html`):** Customer login and account access interface.
- **Shopping Cart (`cart.html`):** Add, review, and manage selected items prior to checkout.
- **Order Tracking (`my_orders.html`):** View order history and current order statuses.
- **Admin Dashboard (`admin.html`):** Interface for managing products, inventory, and store orders.
- **Custom Styling (`style.css`):** Unified styling and responsive layout across all pages.
